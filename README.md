# docTR IPOL demo

This repository contains an IPOL demo wrapper for
[docTR](https://github.com/mindee/doctr). It runs one PNG document image
through a configurable detection and recognition pipeline, then exports final
OCR results and intermediate diagnostic visualizations.

## What the demo exposes

- Detector architecture: all public docTR 1.0.1 FAST, DBNet, and LinkNet variants.
- Recognizer architecture: all public docTR 1.0.1 CRNN, MASTER, SAR, PARSeq,
  ViTSTR, and VIPTR variants.
- Detector tensor size as a free numeric value, aspect-ratio preservation, and
  symmetric padding.
- Page/crop geometry options: straight boxes, rotated boxes, page
  straightening, orientation metadata, and language metadata.
- Structure post-processing: line grouping, block grouping, and paragraph gap.
- Detection thresholds: detector defaults per architecture or custom
  binarization, box score, and box expansion values.
- Visualization controls for labels, confidence display, and sampled crops.

The demo intentionally does not expose `page_max_side`; scale is controlled by
`det_input_size`.

The DDL accepts images up to `6000*6000` pixels to avoid IPOL pre-resizing
large scans before docTR receives them.

## Docker/IPOL behavior

The Docker image is based on `registry.ipol.im/ipol:v2-py3.11-pytorch` and
installs `python-doctr==1.0.1`. Model weights are downloaded during image build
by `preload_models.py` into `DOCTR_CACHE_DIR=/home/ipol/.cache/doctr`.

The runtime path is offline-friendly: it uses `pretrained=True`, but the
weights should already be present in the image.

## Local smoke test

Build:

```bash
docker build -f .ipol/Dockerfile -t doctr-ipol-demo .
```

Create a small test input:

```bash
python3 - <<'PY'
from PIL import Image, ImageDraw
im = Image.new("RGB", (900, 360), "white")
draw = ImageDraw.Draw(im)
draw.text((60, 110), "docTR IPOL demo", fill="black")
draw.text((60, 170), "small smoke test", fill="black")
im.save("/tmp/input_0.png")
PY
```

Run with defaults:

```bash
mkdir -p /tmp/doctr-ipol-out
cp /tmp/input_0.png /tmp/doctr-ipol-out/input_0.png
docker run --rm -v /tmp/doctr-ipol-out:/workdir/exec -w /workdir/exec doctr-ipol-demo \
  python /workdir/bin/run_doctr.py \
  --input input_0.png \
  --det-arch fast_base \
  --reco-arch crnn_vgg16_bn \
  --det-input-size 1024 \
  --preserve-aspect-ratio true \
  --symmetric-pad true \
  --reco-preserve-aspect-ratio true \
  --reco-symmetric-pad false \
  --assume-straight-pages true \
  --export-as-straight-boxes false \
  --straighten-pages false \
  --detect-orientation false \
  --detect-language false \
  --disable-page-orientation false \
  --disable-crop-orientation false \
  --resolve-lines true \
  --resolve-blocks false \
  --paragraph-break 0.035 \
  --bin-thresh 0.1 \
  --box-thresh 0.1 \
  --unclip-ratio 1.0 \
  --draw-labels true \
  --draw-confidence false \
  --min-confidence-display 0 \
  --recognizer-sample-count 24 \
  --visualization-seed 0
```

Validate structured outputs:

```bash
python3 -m json.tool /tmp/doctr-ipol-out/result.json >/dev/null
python3 -m json.tool /tmp/doctr-ipol-out/result_raw_doctr.json >/dev/null
python3 -m json.tool /tmp/doctr-ipol-out/structure_debug.json >/dev/null
head -n 1 /tmp/doctr-ipol-out/words.csv
test -f /tmp/doctr-ipol-out/result.hocr
test -f /tmp/doctr-ipol-out/hocr_error.txt
```

## IPOL CP2 DDL

Use `DDL.json` as the CP2 configuration. The build section expects the
repository to be available at:

```bash
https://github.com/camilomarino/docTR_ipol_demo.git
```

For a private repository, use the SSH URL instead and add the deploy key shown
by CP2 to GitHub.
